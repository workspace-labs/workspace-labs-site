WorkSpace Labs — a human-gated build system, one station at a time

Station 01 — Where it starts

The AI does the work. You keep every decision.

Every project in one orbit, and what moved most recently. Three agents plan, build and check each other; the points where something could be lost or shipped are yours.

Station 02 — The board

Six stages, and three crossings only you can make.

Idea, plan, exam, build, review, complete. The AI walks a card along the road and stops dead at every gate.

What this stoppedCommit, Accept and Reject are not promises an agent might forget under pressure. The commands do not exist on the agent's side at all.

Station 03 — The crew

Grok asks. Claude builds. Codex checks.

Three agents in one session, each watching the board for the work that belongs to it — and refused the work that does not.

What this stoppedThe builder cannot check its own work. Reviewing is a separate lane, and the agent that wrote the code is refused the command that would sign it off.

Station 04 — The exam

The test list is written before the build starts.

Open any task and its whole journey is there — stage by stage, with the timestamps of every move.

What this stoppedNobody marks their own homework. A different agent writes what must be tried to prove the build works, and the builder has to hand it back ticked, item by item.

Station 05 — What it remembers

Nothing gets solved twice.

Every fixed bug, every lesson and all twenty-eight rules live in one read-only place the agents must read before they guess — 210 notes and counting.

What this stoppedThe loop cannot run forever. On the third round of find-and-fix the board stops offering another round and asks you one question instead.

Station 06 — The roadmap

The next move is never a guess.

Every project keeps its own ordered steps, so a session picks up exactly where the last one stopped.

Station 07 — What needs you

One page that says whether you are needed today.

Written from the board itself, with every sentence traced to a real task — and a set of read-only inspectors you can send into a project.

Station 08 — Saying it once

Write it in your own words. Leave with the exact prompt.

One card in, one finished prompt out — and it invents nothing you did not say.

Station 09 — The end of the line

The machine moved fast. Every decision stayed yours.

Every project, live, with how far it has come — read from the real files, never typed in. That is the whole system; the rest is the bookkeeping that keeps it true.
